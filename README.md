- HTTP request and POST analysis
- HTTP authentication and session artifacts
- FTP authentication analysis
- NTLM / NetNTLMv2 extraction
- Kerberos traffic analysis
- WinRM / PSRP stream analysis
- Credential and token pattern hunting
